# SteelMaker

DXF 모델 공간에서 절단 목록 후보와 근거 객체 핸들을 반환하는 Python MVP입니다. 근거가 없거나 여러 해석이 가능한 필드는 `미확인`으로 표시합니다. 원본 프로젝트 ZIP을 확보할 수 없어 제공된 DWG를 기준으로 새로 구현했습니다.

## 실행

Python 3.11 이상을 사용합니다.

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python steelmaker.py drawing.dxf
```

DWG는 먼저 DXF로 변환합니다. 실도면 검증에는 GNU LibreDWG 0.14를 사용했습니다.

```sh
dwg2dxf -o drawing.dxf drawing.dwg
uvicorn api:app --port 8000
```

별도 터미널에서 API를 호출합니다.

```sh
curl http://127.0.0.1:8000/health
curl -F 'file=@drawing.dxf' http://127.0.0.1:8000/analyze
```

## 지원하는 도면 표기

- `100*50`과 `보이는면이 50` 같은 두 줄 규격 주석을 읽습니다. 밀리미터 도면에서만 이 표기의 보이는 면을 mm로 반환합니다.
- 규격 주석을 두 선으로 이루어진 지시선에 연결할 수 있고 지시점이 유일한 평행 부재 변 사이에 있을 때 길이 후보를 찾습니다. 두 변의 길이 방향 범위가 같고 선형 치수의 양 끝점이 부재 변의 끝점과 일치할 때만 길이를 채웁니다. 치수 텍스트가 덮어쓰였거나 도면 단위가 mm로 확인되지 않으면 이 방식으로 길이를 채우지 않습니다.
- 모델 공간의 여러 줄 MTEXT에 아래처럼 명시하면 일곱 필드를 직접 읽습니다. 각도는 표기된 값을 도 단위로 옮기며 기준 방향을 바꾸지 않습니다. 단위 없는 길이와 보이는 면은 mm 도면에서만 읽습니다. 동일 항목의 값이 충돌하면 `미확인`으로 표시합니다.

```text
절단
규격: 100×50
길이: 600 mm
좌 절단각: 45°
우 절단각: 90°
보이는 면: 50 mm
구분: 벨트
수량: 3ea
```

응답의 `items`는 지원되는 주석별 후보 목록입니다. `source_handle`은 주석을, `evidence`는 확인된 필드의 DXF 객체를 가리킵니다. `4ea` 같은 독립 수량 표기는 바로 왼쪽 프레임의 제작 수량입니다. 바닥의 가로 치수와 양쪽 기둥·바닥선으로 범위를 확인한 프레임 중 같은 높이 범위에 있는 가장 가까운 왼쪽 프레임을 찾습니다. 대응이 모호하거나 한 프레임에 수량 표기가 여러 개면 `unassigned_quantities`에 남깁니다. 연결된 표기와 프레임의 근거는 `frames`에 기록합니다.

지시선이 프레임을 가리키면 `frame_quantity`를 표시합니다. 지시선이 부재 1개를 유일하게 가리키거나 절단 주석에 `프레임당 수량: 2ea`가 명시되면 `quantity_per_frame`에 기록하고, 두 값을 곱해 해당 행의 총 절단 수량 `quantity`를 계산합니다. 예를 들어 프레임 4개에 프레임당 부재 2개가 필요하면 총 8개입니다. 명시한 총수량이 계산값과 충돌하면 `미확인`으로 표시합니다. 여러 후보 행을 합치거나 주석 없는 대칭 부재의 수량을 추가하는 기능은 미구현입니다.

## 테스트 결과

2026-11-09에 Python 3.14에서 **15개 통과**했습니다.

- 합성 DXF 14개 테스트에서 길이와 근거 연결, 치수 덮어쓰기, 모호한 부재, 단위 누락, 충돌 필드, 명시된 벨트·옆전과 좌우 각도, FastAPI 정상 응답과 잘못된 업로드 처리를 확인했습니다. 프레임 수량 연결, 수량 곱셈, 중복 표기 및 총수량 충돌도 검사했습니다.
- 제공된 DWG를 DXF로 변환한 후 명령행과 API로 검증했습니다. 규격·보이는 면 6개, 끝점 근거가 있는 길이 3개, 프레임 수량 표기 3개를 확인했습니다. 수량 표기 3개를 각 프레임에 연결했고 지시선으로 특정된 부재 후보 6개에 수량을 계산했습니다. 나머지 길이 3개와 개별 부재의 좌우 각도·벨트/옆전은 `미확인`으로 남았습니다.
- 변환기는 일부 DWG 객체와 치수 연관 정보에 경고를 출력했습니다. 변환된 DXF의 표기와 끝점에 대해 검증했으며 원본 DWG와 모든 객체의 일치 여부는 미검증입니다. 원본과 변환 도면은 저장소 외부에 보관합니다.

```sh
python -m pip install -r requirements-test.txt
python -m pytest -q
STEELMAKER_SAMPLE_DXF=/absolute/path/to/drawing.dxf python -m pytest -q
```

도면 경로를 지정하면 실도면 파싱과 API 응답 일치 검사를 추가로 실행합니다.

## 미구현 및 미검증

- **미구현** — 선 형상에서 좌우 절단각 자동 계산, 벨트/옆전 자동 분류, 지원 범위를 벗어난 프레임의 수량 연결, 블록·배치 도면에서 절단 항목 추출, 재고 비교와 절단 최적화, OpenAI Agents SDK 통합.
- **미검증** — 다른 실도면 및 CAD 내보내기 방식과의 호환성, 제작 전 부재별 절단값의 현장 대조, 이전 프로젝트에서 보고된 Agents SDK 실행.
